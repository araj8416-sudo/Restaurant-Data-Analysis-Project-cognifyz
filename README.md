# Restaurant-Data-Analysis-Project
🍽️ Restaurant Data Analysis – Internship Project

This repository contains the work I completed during my Data Analysis Internship at Cognifyz Technologies.
The project focuses on analyzing restaurant data to uncover trends, insights, and patterns using Python, Pandas, Matplotlib, and Seaborn.

📌 Project Levels & Tasks
🔹 Level 1

Top Cuisines: Identify the most common cuisines and their distribution.

City Analysis: City with the highest number of restaurants, average ratings, and top-rated city.

Price Range Distribution: Visualizing distribution of restaurant price ranges.

Online Delivery: % of restaurants offering delivery & rating comparisons.

🔹 Level 2

Cuisine Combination: Common cuisine pairings and their ratings.

Geographic Analysis: Mapping restaurant clusters using latitude & longitude.

Restaurant Chains: Identifying chains and analyzing their ratings/popularity.

Restaurant Reviews: Keyword analysis from positive & negative reviews.

🔹 Level 3

Votes Analysis: Restaurants with highest/lowest votes & correlation with ratings.

Price Range vs. Services: Relationship between price range, online delivery, and table booking.

🛠️ Tech Stack

Languages: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn, Plotly

Tools: Jupyter Notebook
